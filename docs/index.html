KEEP THE PREFIX. CHANGE THE SCALE.

Fine detail.
Fast grouping.

A timestamp is assigned to an interval at the level you choose. To group at a coarser level, mask the finer prefix bits and update the level header. No calendar parsing. No scan through individual seconds.

These integer keys can make temporal grouping and filtering much faster. Use a coarser prefix as a MapReduce key or a time bucket for clustering, while retaining finer intervals in your data.

This is an efficient grouping primitive, not a clustering algorithm. Actual speed depends on the workload, storage and execution engine; no benchmark claim is made here.

TIX IS THE FAMILY

Choose the footprint.
Keep the hierarchy.

Six bits encode the level. The remaining bits hold a left-aligned time prefix. TIX48 is the default; TIX32 trades resolution for a smaller footprint, while TIX58 retains finer detail.

FormatMax levelFinest duration
TIX322616,384 seconds
TIX48 · default420.25 seconds
TIX5852244.140625 microseconds

All share the same 240-second domain, centered on the Unix epoch. Level 40 is always exactly one second wherever the chosen width supports it. TIX32 stops at level 26.

Width is external metadata. A code must be decoded with its width; raw integers are not interchangeable across widths. Exact conversion needs a level supported by both formats.

SMALL ENOUGH TO TAKE WITH YOU

Copy. Paste. Use.

Plain Python. Header-only C.
No package, build system or third-party dependency.

Complete tix.py. Core times use integer quarter-seconds by default. Use encode_seconds() for Unix seconds.

Includes encode/decode, hierarchy, containment, overlap, range covering, hex and Base64url. C defaults to TIX48; define TIX_BITS before including the header for another width. Python takes bits=48 by default.

Exact boundaries.
Honest precision.

TIX encodes a temporal interval, not an instantaneous event. A fine interval describes resolution, not the accuracy of an observation. A coarser interval may better reflect what is actually known.

Time is POSIX/Unix time. Leap seconds have no separate representation. Out-of-domain dates, invalid levels and noncanonical codes are rejected, never clamped.

The reference range cover is exact at the finest supported level. At a requested coarser limit it rounds outward, so it can include time outside the requested range.
